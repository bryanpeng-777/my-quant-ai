# 腾讯 IFRS 二级指标 PDF 提取备忘（三费率 / EBITDA）

## 三费率（腾讯 IFRS 口径说明）

腾讯简明利润表**不单独列示研发费用**，AI/游戏等研发支出多计入 **「一般及行政开支」**。

二级分析中的**三费率**按以下规则处理：

```
三费率 = (销售及市场推广开支 + 一般及行政开支) / 收入 × 100
```

脚注必须写：**「研发并入一般及行政开支，未单列重复加计。」**

PDF 提取行（人民币百万元，业绩公布「管理层讨论及分析」对比表）：
- 銷售及市場推廣開支 / 销售及市场推广开支
- 一般及行政開支
- 收入（当期列）

`westock-data` 港股字段对应：`SalesExpense` + `AdministrationExpense`，单季值需累计报差分。

## EBITDA 利润率（官方披露）

**口径**（业绩 PDF 脚注）：经营盈利 ± 其他（不含 D&A）+ 物业/设备/投资物业折旧 + 使用权资产折旧 + 无形资产及土地使用权摊销。

**提取位置**：业绩公布 PDF 中 `EBITDA (a)` 行及「经营盈利与 EBITDA 之间的调节」表。

**单位**：人民币百万元；利润率 = EBITDA ÷ 收入（同 PDF 对比表中的「收入」当期列）。
